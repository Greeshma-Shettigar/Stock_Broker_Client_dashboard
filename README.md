Stock Broker Client – Real-Time Web Dashboard

A real-time stock broker client dashboard built using React, Socket.IO, and Bootstrap.
This application allows users to sign up, log in securely, subscribe to stocks, and view live price updates without refreshing the page.

🚀 Features

🔐 User Authentication (Signup & Login with validation)

🔒 Protected Dashboard Route

📡 Real-Time Stock Price Updates using WebSockets

🔴🟢 Price Change Indicators (Increase / Decrease)

🚪 Secure Logout Functionality

Tech Stack
Frontend
React (Vite), React Router DOM, Bootstrap, Socket.IO Client

Backend
Node.js, Express.js, Socket.IO
